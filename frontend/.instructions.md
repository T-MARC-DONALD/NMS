# Frontend Instructions
Frontend - React Vite Network Management System Dashboard

## Key Files & Components
- App.jsx: Main router & navigation, connection status
- pages/Dashboard.jsx: Overview with charts & summary stats
- pages/Devices.jsx: Device list, add/delete operations
- pages/DeviceDetail.jsx: Device details, edit, interfaces, events
- pages/Events.jsx: Event list with severity filter & resolve action
- pages/Discovery.jsx: Auto-discovery for network scanning
- pages/Billing.jsx: Traffic usage & SLA information
- api.js: Axios client for API communication
- index.css: Tailwind CSS styling

## Running Frontend
1. Install dependencies: npm install
2. Start dev: npm run dev
3. URL: http://localhost:3000
4. Build: npm run build (creates dist directory)

## Architecture
- React Router for navigation (5 pages + device details)
- Axios API client with base URL /api (proxied to http://localhost:5000)
- Vite build tool (dev server port 3000)
- Tailwind CSS for responsive design
- Chart.js for visualizations (Pie, Bar charts)
- Auto-refresh every 30 seconds on dashboard

## Dependencies
- react: UI framework
- react-router-dom: Navigation
- axios: HTTP client
- chart.js & react-chartjs-2: Charts
- tailwindcss: CSS framework
- vite: Build tool

## Key Features Per Page
- Dashboard: Real-time stats, device status, events by severity pie chart
- Devices: Device list, add form, delete, view details link
- Events: Filterable list (severity, status), resolve button
- Discovery: Network range scan, bulk add devices
- Billing: Traffic tracking, cost calculation, SLA info
- DeviceDetail: Edit device, view interfaces table, recent events

## Important Notes
- Health check on app load & every 30 seconds
- Automatic refetch on data mutations
- Responsive grid layout (1 col mobile, 2+ cols tablet/desktop)
- Error handling with user-friendly messages
- Pagination support for lists
- Status indicators: device.status (up/down/unknown), event.severity (critical/warning/info)

## API Client Usage
import { deviceAPI, eventAPI, statsAPI } from './api'
- deviceAPI.getAll(page, perPage, status)
- deviceAPI.getById(id), create(data), update(id, data), delete(id)
- eventAPI.getAll(page, perPage, filters), resolve(id)
- statsAPI.getSummary(), getEventsBySeverity()
