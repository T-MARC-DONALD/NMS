# Backend Instructions
Backend - Python Flask SNMP Network Management System

## Key Files
- app.py: Flask application entry point & scheduler
- api.py: REST API endpoints for all operations
- models.py: SQLAlchemy database models
- snmp_collector.py: SNMP data collection & device polling
- config.py: Configuration settings
- requirements.txt: Python dependencies (Flask, pysnmp, SQLAlchemy, etc.)

## Running Backend
1. Create virtual environment: python -m venv venv
2. Activate: .\venv\Scripts\Activate.ps1 (Windows) or source venv/bin/activate (Mac/Linux)
3. Install: pip install -r requirements.txt
4. Run: python app.py
5. Server: http://localhost:5000

## API Endpoints (/api)
- Devices: GET /devices, POST /devices, GET /devices/{id}, PUT /devices/{id}, DELETE /devices/{id}
- Events: GET /events, PUT /events/{id}/resolve
- Stats: GET /stats/summary, GET /stats/events-by-severity
- Health: GET /health

## Key Configuration (config.py)
- SNMP_VERSION: '2c' (SNMPv2 Community)
- SNMP_TIMEOUT: 1 second
- SNMP_COMMUNITY_RO: 'public' (read-only)
- SNMP_COMMUNITY_RW: 'private' (read-write)
- POLLING_INTERVAL: 60 seconds
- DATABASE: SQLite (./nms.db)
- SCHEDULER: APScheduler with threadpool executor

## Database Models
- NetworkDevice: Network devices with SNMP config
- NetworkEvent: Events/traps/alerts from devices
- NetworkInterface: Interface inventory from devices
- BillingRecord: Traffic & cost tracking per IP

## Important Notes
- Uses PySnmp for SNMP queries
- Automatic device polling every 60 seconds (configurable)
- SNMP OIDs: sysUptime, sysName, interfaces table, traffic counters
- Events auto-created on device up/down transitions
- Database auto-created on first run
